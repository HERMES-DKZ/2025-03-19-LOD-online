OpenRefine

Für diesen Workshop benötigst du die Software OpenRefine und einen Webbrowser. Hinweis: OpenRefine ist ein Java Programm, welches lokal in deinem Webbrowser läuft (nicht auf einem Server). Es läuft zwar innerhalb eines Webbrowsers, aber es ist daher keine Internetverbindung erforderlich.

  • Windows
  • MacOS
  • Linux
  1. Check that you have either the Firefox or the Chrome browser installed and set as your default browser. OpenRefine runs in your default browser. It will not run correctly in Internet Explorer.
  2. Download software from http://openrefine.org/
  3. Create a new directory called OpenRefine.
  4. Unzip the downloaded file into the OpenRefine directory by right-clicking and selecting "Extract ...".
  5. Go to your newly created OpenRefine directory.
  6. Launch OpenRefine by clicking openrefine.exe (this will launch a command prompt window, but you can ignore that - just wait for OpenRefine to open in the browser).
  7. If you are using a different browser, or if OpenRefine does not automatically open for you, point your browser at http://127.0.0.1:3333/ or http://localhost:3333 to use the program.

  3. Create a new directory called OpenRefine.

OpenRefine-Erweiterung RDF Transform

Die OpenRefine-Erweiterung RDF Transform ermöglicht es, Daten aus dem CSV-Format in das RDF-Format zu überführen, ohne dass Programmierkenntnisse erforderlich sind. Nachdem du OpenRefine erfolgreich installiert hast, kannst du die Erweiterung RDF Transform als ZIP-Datei hier herunterladen.

  • Windows
  • MacOS
  • Linux
  1. Find your workspace by opening Open Refine
  2. Click Open Project in the sidebar. At the bottom of the screen, click Browse workspace directory. A file-explorer or finder window will open in your workspace. Note that path
  3. If not already there, create a folder called "extensions" and unzip the rdf-transform data into that directory.
  4. Restart OpenRefine
  1. Entpacke die ZIP-Datei.
  2. Verschiebe den entpackten Ordner `rdf-transform` in ein Verzeichnis mit dem Namen `extensions` innerhalb deines OpenRefine-Arbeitsbereichs. Hinweis: Du kannst den Pfad zu Deinem OpenRefine-Arbeitsbereich finden, indem Du OpenRefine starten und in der Seitenleiste auf "Open Project“ klickst. Klicke anschließend am unteren Rand des Bildschirms auf „Browse workspace directory“. Es sollte sich ein Finder-Fenster mit dem Pfad `~/Library/Application Support/OpenRefine` öffnen.
  3. Beende und starte OpenRefine neu.
